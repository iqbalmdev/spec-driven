## Guidelines

- **Goals, not implementation** — "capture notes" not "add a Markdown editor component"
- **One story, one outcome** — split large features into multiple stories
- **Checkboxes for done** — no subjective completion
- **Log open items** — unresolved questions block the Clarification Gate
