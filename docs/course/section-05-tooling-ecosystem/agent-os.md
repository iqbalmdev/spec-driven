# AgentOS — Lesson 1 (Section 5)

Builder Methods **AgentOS**: a discipline for persistent project memory and a gated feature lifecycle.

## Narrative arc (lesson transcript)

1. **Problem** — AI amnesia; re-explaining mission, stack, and roadmap every session.
2. **`/plan product`** — run once at project start; anchor survives all future sessions.
3. **Memory files** — `plan.md` (feature drift), `roadmap.md` (priority hallucinations), `techstack.md` (stack guessing).
4. **`shape-spec`** — ask-before-guess dialogue; decisions saved to `requirements.md`.
5. **Clarification gate** — zero unresolved items in `requirements.md` before moving on.
6. **`/create-tasks`** — atomic decomposition → dependency-ordered `tasks.md` with verification.
7. **Build** — **implement tasks** (control, sequential) vs **orchestrate tasks** (speed, focused specialists).
8. **Payoff** — consistency; you architect intent and trade-offs; agents execute bounded work.
