# Section 6 · Lesson 1 — Living Specs & Executable Guardrails

**The Explainer** transcript: close the gap between what you plan to build and what ships.

## Topics

1. **Drift** — specs vs shipped features; budget, timeline, trust.
2. **Linked intent** — requirements written to produce tests (not doc vs code silos).
3. **Executable guardrails** — specs that validate continuously.
4. **Test-driven specs** — validation embedded in the spec; shared definition of done.
5. **Scenarios** — happy path, edge cases, error cases.
6. **Given / When / Then** — structured, unambiguous behavior.
7. **Test-first gate** — governance before implementation; failing tests first.
8. **Property-based tests** — Hypothesis (Python), FastCheck (JS/TS).
9. **Traceability table** — requirement ID → scenario → command → PR.
